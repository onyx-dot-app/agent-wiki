# Wiki seed

Files in this directory are copied into the `wiki-data` volume on first boot
to give the system something to render. Replace with your own starter content.

## Suggested layout

```
projects/
  <project-name>.md     # high-level plan an agent can read and update
people/
  <name>.md             # what someone is working on
sales/
  <account>.md          # call notes + action items
```
